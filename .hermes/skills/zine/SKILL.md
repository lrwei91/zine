# 拾页 zine

原生 HTML/CSS/JavaScript 的照片纸刊静态展示站。

## 边界

- 保持静态架构、`index.html` 部署入口、`styles.css` 语义 token 和 `app.js` 渐进增强。
- 这是明确标注的前端演示，不连接真实账户、上传、生成或持久化服务。
- 用户选择的图片只在当前浏览器内校验和预览，不上传、不保存；不要把演示入口包装成已接入后端。
- 参考站只提供已登记的信息结构和位置关系，不复制 Logo、作品、账户信息、社会证明或专有文案。
- 默认只做本地修改和验证；提交、推送、部署和 DNS 变更需要用户明确授权。

## 核心结构

| 区域 | 文件 | 约束 |
|---|---|---|
| 页面 | `index.html` | 保持桌面侧栏、移动底部导航、作品瀑布流和创作入口层级 |
| 视觉 | `styles.css` | 使用现有微暖纸面、近黑油墨、荧光黄和细网格 token |
| 交互 | `app.js` | 原生 `dialog` 支持 Escape、焦点返回和键盘焦点；JS 失效仍可读 |
| 媒体 | `public/assets/` | 只放原创、已确认可用的静态作品资源 |
| 门禁 | `tests/check.mjs`、`vercel.json` | 检查入口、12 张作品、关键页面契约和静态部署响应头 |

## 使用

```bash
# 开始前保护已有改动
git status --short --branch

# 项目门禁
npm run check
node --check app.js
git diff --check

# 本地静态服务（项目脚本使用 4173 端口）
npm run dev
```

涉及布局、交互或媒体时，打开真实浏览器检查 320、390、768、1024、1440 CSS px、移动导航、对话框、键盘焦点、减弱动效和控制台。

## 当前 5 大坑

### 1. 把演示功能写成真实后端

**触发**：新增上传、登录、生成或保存按钮。**表现**：用户以为数据会离开浏览器或被持久化。**修法**：保持当前演示文案和本地边界；若要接后端，先补产品说明、安全设计和失败处理。

### 2. 破坏无 JavaScript 降级

**触发**：把作品内容完全移到运行时渲染。**表现**：脚本禁用时品牌说明或作品消失。**修法**：HTML 保留可读内容，JavaScript 只做增强和交互。

### 3. 对话框只支持鼠标

**触发**：只实现点击打开/关闭。**表现**：Escape、焦点返回或键盘焦点不完整。**修法**：复用原生 `dialog` 语义，验证打开、关闭、回焦和 reduced-motion。

### 4. 复制参考站资产或文案

**触发**：为追求视觉相似直接搬运作品、Logo 或社会证明。**表现**：原创边界和来源登记失效。**修法**：只按 `design-brief.md` 登记的信息结构重新实现，素材保持原创。

### 5. 把构建成功当视觉完成

**触发**：`npm run check` 通过就结束。**表现**：移动端溢出、导航遮挡、媒体缺失或控制台错误未发现。**修法**：补真实浏览器视口矩阵和关键键盘路径验证。
